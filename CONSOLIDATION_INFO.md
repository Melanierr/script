# Roblox Scripts Consolidation

## Migration Summary

This repository now consolidates three separate Lua/LuaU Roblox script repositories:

### 1. **old-scripts/** (from Melanierr/old-scripts)
- Contains legacy Roblox scripts from various games
- Includes scripts like Anti Lag, ESP utilities, and game-specific tools
- Status: Archived

### 2. **Miscc/** (from Melanierr/Miscc)
- Contains miscellaneous Roblox scripts for various games
- Includes game-specific GUIs like Ability Wars, Arsenal, Azure Latch, etc.
- Status: Archived

### 3. **Main script folders** (already in Melanierr/script)
- Organized game-by-game
- Contains reworked and active scripts
- Status: Primary repository
